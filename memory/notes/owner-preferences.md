# Owner working preferences

How the owner likes to work, gathered from the August and September sessions. Not derivable
from the code; product decisions themselves are in `docs/decisions.md`.

- When there are several ways to enhance the experience, present the options and let the owner
  pick. Do not pick silently.
- Terminology the owner finds jargon is replaced in the UI, README and docs ("Journal" became
  "History"; "Sessions" was considered and rejected).
- The phone is connected intermittently. Resume device work only when told it is reconnected,
  and keep a list of what still needs a device check (see `device-testing.md`).
- Dropped ideas stay dropped unless the owner reopens them: code-drawn move animations (four
  demo attempts, 2026-08-29), combination memory, ears-only, two-player, rhythm and custom
  reaction presets. If move animations return, it is designer Lottie/Rive clips only.
- Still unconfirmed by the owner: that "jab" is pronounced correctly after the forced en-US
  voice fix.
- Conventions originated on the owner's `../optum_launcher` repo (2026-08-27); boxer_os mirrors
  them so agent instructions carry across projects.
